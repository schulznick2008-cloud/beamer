# M0-Werkzeuge

Anleitung: `docs/teleport/M0-TEST.md`.

| Datei | Rechner | Zweck |
|---|---|---|
| `mac_netz.sh` | Mac | WLAN-Daten und Ping-Perzentile zur Fritzbox und zum PC (ändert nichts) |
| `awdl.sh` | Mac | AWDL-Status, vorübergehend ab- oder einschalten (sudo, nur bis zum Neustart) |
| `pc_netz.ps1` | PC | Netzwerkdaten und Ping-Perzentile zum Mac (ändert nichts) |
| `stoppuhr.html` | Mac | Millisekunden-Uhr für die Glass-to-Glass-Fotos |
| `schaerfe.html` | Mac | Testbild für Text, Farben und Linien |
